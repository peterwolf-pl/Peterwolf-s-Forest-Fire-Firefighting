# Changelog

## 1.1.11 - 2026-08-18

- `/fireincident douse` (and `/fireextinguish` / `/gaspozaru`) now also removes airborne sparks whose origin, current flight or landing is inside the radius, so a doused patch no longer reignites from leftover embers.
- `/fireincident extinguish` and `/firetest clear` clear sparks for the same incident / world.

## 1.1.10 - 2026-08-02

- Rebuilt the Firefighting Water Bomber as a heavy, single-engine, high-wing amphibious flying boat.
- Added a stepped rescue-boat hull, central elevated engine and four-blade propeller, wing struts, stabilising floats, a framed two-seat cockpit, tall tail and compact amphibious landing gear.
- Added visible water-tank panels, fill connections, water-level gauge, four belly drop doors and a protected retractable intake system.
- Replaced the aircraft atlas and inventory icon with matching white, firefighting-red and rescue-yellow Minecraft pixel art.
